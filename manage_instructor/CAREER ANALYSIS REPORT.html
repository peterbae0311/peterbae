EUV 리소그래피 공정 제어

공정 데이터 기반 문제 해결

센서 데이터 분석과 데이터 시각화 대시보드를 구축하여 공정 상태를 실시간으로 모니터링하고 이상을 조기에 포착합니다. 데이터 기반 분석을 통해 패키징 라인 불량률을 1.2%에서 0.3%로 낮추는 등 공정 안정화에 기여했습니다.
